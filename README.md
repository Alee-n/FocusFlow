# FocusFlow – Smart Productivity Planner

FocusFlow is a Flask-based web application that generates personalized focus plans based on user input such as available time and energy level.

## Live Demo

https://focusflow-6dz0.onrender.com

## 🚀 Features
- Adaptive focus session planning
- Productivity score system
- Personalized feedback
- Clean and minimal UI
